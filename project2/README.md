# Project 2: Digital Advertising Budget Optimizer (Limelight context)

**Question:** Where should we spend the next Rs. 1 million across Facebook, Instagram, Google, TikTok and YouTube?

This project continues Project 1 (Limelight YouTube analysis). All advertising data is **simulated** (real Limelight ad data is not public); the simulator is calibrated with Project 1 findings (Eid/Sale: high reach, low engagement; Unstitched/fabric: best engagement).

## Files
- `Project2_Ad_Budget_Optimizer.ipynb`: full notebook with outputs (run top to bottom in Google Colab; Spark is installed automatically)
- `benchmark_seconds.csv`: run times of the three engines (Google Colab run)
- `ads_10000.csv`, `ads_100000.csv`: simulated data samples (the 1M and 10M files are generated by the notebook and are too large for GitHub)
- `Project2_Description.docx`: 2-page description submitted on the LMS

## Method
1. Simulate ad records (date, campaign, platform, impressions, clicks, spend, conversions, revenue, age, gender, city, device) at 10k, 100k, 1M and 10M rows.
2. KPIs: CTR, CPC, conversion rate, CPA, ROAS (computed from group sums).
3. Benchmark Pandas vs MapReduce (pure-Python map/shuffle/reduce) vs Spark.
4. Response curve per platform (revenue = a * spend^b), marginal-ROAS optimiser for Rs 1M, 200-sample bootstrap for stability, out-of-sample validation.

## Key results
| Records | Pandas (s) | MapReduce (s) | Spark (s) |
|---|---|---|---|
| 10,000 | 0.03 | 0.06 | 1.63 |
| 100,000 | 0.17 | 0.29 | 2.62 |
| 1,000,000 | 1.33 | 2.75 | 9.58 |
| 10,000,000 | 14.04 | 30.35 | 65.89 |

- Pandas was fastest at every size on one machine; Spark grew only ~40x in time for 1000x more data (Pandas ~470x), so its advantage appears when data no longer fits on one machine.
- Recommended split of the next Rs 1M (bootstrap average): **Google ~58%, Instagram ~42%**, others ~0%. The exact split between Google and Instagram is uncertain (Instagram share ranged 0-84% across resamples).
- Validation on unseen weeks: MAPE 17.8% (response-curve model) vs 20.7% (constant-ROAS baseline).

## Limitations
Simulated data; YouTube ROAS is last-click only; timings are from one Colab machine, not a cluster.
